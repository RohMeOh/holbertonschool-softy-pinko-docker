# Docker & Web Services

**Holberton School · Software Engineering Coursework**

Progressive containerization exercises combining a Flask API, web frontend, Nginx proxy and multi-container orchestration.

## Technology and concepts

Docker, Docker Compose, Python, Flask, Nginx, networking and reverse proxies.

## Modules

| Directory | Focus |
| --- | --- |
| [`task0/`](./task0/) | Build a basic container image. |
| [`task1/`](./task1/) | Run a Python service in a container. |
| [`task2/`](./task2/) | Separate backend and frontend container builds. |
| [`task3/`](./task3/) | Develop container networking for the application. |
| [`task4/`](./task4/) | Coordinate services using Docker Compose. |
| [`task5/`](./task5/) | Add a reverse proxy to the stack. |
| [`task6/`](./task6/) | Extend the architecture to multiple backend instances and load distribution. |

## Working with the exercises

Review the individual directory README files and exercise source before running or compiling them. Each task may have its own dependencies, test driver, or required inputs; do not assume every file is a standalone program.
